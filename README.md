# Salão de Beleza Jeito de Mulher 💅

## 📌 Sobre o Projeto

O **Salão de Beleza Jeito de Mulher** é um projeto desenvolvido em linguagem C como parte dos estudos de programação. O objetivo é criar um sistema simples para gerenciar operações de um salão de beleza, incluindo cadastro de clientes, produtos e serviços, além da compra de produtos.

O projeto utiliza conceitos fundamentais da programação, como estruturas (`struct`), funções, arrays, estruturas de repetição e condicionais.

## 🚀 Funcionalidades

- **Cadastro de clientes:** permite registrar nome, telefone e CPF dos clientes.
- **Validação de CPF:** verifica se o CPF informado é válido utilizando os dígitos verificadores.
- **Cadastro de produtos:** permite registrar nome, preço e quantidade disponível em estoque.
- **Cadastro de serviços:** permite cadastrar serviços do salão, seus valores e os profissionais responsáveis.
- **Compra de produtos:** permite selecionar produtos, informar quantidades e calcular o valor total da compra.

## 🛠️ Tecnologias Utilizadas

## 💻 Como Executar

### Pré-requisitos

- Um compilador C, como GCC ou Clang.
- Visual Studio Code (opcional, para editar e executar o código).

### Compilação

No terminal, navegue até a pasta do projeto e execute:

```bash
gcc salao_jeito_de_mulher.c -o salao
```

### Execução

No macOS ou Linux:

```bash
./salao
```

No Windows:

```bash
salao.exe
```

## 📋 Menu do Sistema

O programa apresenta opções para:

2. Cadastrar produtos.
3. Cadastrar serviços.
4. Comprar produtos.
